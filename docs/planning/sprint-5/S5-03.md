# S5-03 — Complete critical Gmail-to-application browser smoke and fix async invalidation

Status: proposed local ticket.

## 1. Goal
Fix frontend presentation defects where application-detail invalidation occurs prematurely, and provide a reliable E2E browser smoke test.

## 2. Problem / Gap
The frontend `gmail.tsx` synchronization/refetch behavior relies on `lastSyncedAt`, which updates when ingestion completes, completely missing the backend-delayed application-detail invalidations that happen asynchronously during AI processing.

## 3. Proposed Implementation
Delay query invalidations or implement a bounded refresh tied to the actual terminal processing condition of the emails. Provide a browser smoke test that uses real local workers to ensure end-to-end UI correctness.

## 4. Acceptance Criteria
- Frontend correctly invalidates cache only when AI processing is terminal, or uses a bounded refresh.
- Browser E2E smoke test runs and passes with real local workers.
