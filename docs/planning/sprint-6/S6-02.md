# S6-02 — Record source email evidence for timeline events and AI actions

Status: proposed local ticket.

## 1. Goal
Expose owned source evidence and recording semantics in application history.

## 2. Problem / Gap
Events lack source metadata, making it impossible for the user to understand which email triggered a timeline event or AI action.

## 3. Proposed Implementation
Extend the event schemas with `recordedAt` and `sourceEmail` metadata. Check source ownership to prevent cross-user data leakage.

## 4. Acceptance Criteria
- Timeline events expose the source email ID, subject, and sender securely.
- Cross-user source identifiers are not disclosed.
