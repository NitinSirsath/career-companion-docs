# S6-04 — Connect manual status correction in the application frontend

Status: proposed local ticket.

## 1. Goal
Connect manual status correction in the application frontend.

## 2. Problem / Gap
The frontend currently lacks UI for manual status correction.

## 3. Proposed Implementation
Add a status correction editor UI in `applications.$id.tsx` that consumes the `effectiveStatus` and sends the `PATCH` request with the correct `expectedUserStatusRevision`.

## 4. Acceptance Criteria
- UI displays current effective status.
- User can override status.
- UI handles 409 Conflict correctly by blocking save and prompting a refresh.
